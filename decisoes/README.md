# Decisões

> Decisões de protocolo do Wolfpack que sobrevivem ao tempo.

Esta pasta guarda decisões duráveis. Não é uma ata de reunião. Não é um changelog. É um registro durável de por que o Wolfpack é do jeito que é.

## O que cabe aqui

- Decisões de protocolo que afetam a forma como o Wolfpack opera.
- Decisões de processo que vão guiar mais do que uma única entrega.
- Decisões explícitas de escopo (o que é e o que não é responsabilidade do Wolfpack).

## O que **não** cabe aqui

- Decisões pontuais sobre uma tarefa específica.
- Decisões operacionais que dependem de infraestrutura privada.
- Decisões que envolvam clientes, casos reais, dados de terceiros.

## Como uma decisão é registrada

Cada decisão aqui segue o mesmo formato:

- **Contexto.** O que motivou a decisão.
- **Decisão.** O que foi fechado.
- **Consequência.** O que muda em comportamento daqui em diante.
- **Quando revistar.** Em que condições a decisão deixa de valer.

A primeira decisão registrada neste repositório é a adoção do lema *Esse quam videri*, tratada em [`diario/2026/08/lema-adotado.md`](../diario/2026/08/lema-adotado.md).
