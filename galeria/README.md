# Galeria

> Imagens e visuais públicos do Wolfpack.

Esta pasta está vazia nesta V1. Foi criada para receber, no futuro, visuais públicos do Wolfpack — diagramas, fotos de encontros, mockups, registros visuais de marcos.

## Política de entrada

Só entra aqui material que satisfaça três critérios:

- **Público.** Não traz informação privada sobre pessoas, infraestrutura, operação ou terceiros.
- **Sanitizado.** Não exibe tokens, paths, IDs internos, prints de painéis, dados pessoais.
- **Autorizado.** A fonte dos direitos permite publicação. Se há rosto, há autorização.

## O que **não** entra

- Prints de dashboards, logs, alertas, métricas.
- Fotos de telas internas do sistema.
- Imagens com dados pessoais identificáveis.
- Qualquer asset que exponha topologia, rede, credenciais ou ambiente.

## Como contribuir

Abra um branch, anexe o asset, abra PR. A revisão humana é obrigatória antes de mesclar.
